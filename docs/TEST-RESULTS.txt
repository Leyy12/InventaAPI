5. DEFECTS AND ISSUES FOUND
================================================================================
  #  Severity  Finding
  -  --------  -----------------------------------------------------------------
  1  High      Deployed developer page redirects visitors to localhost:3000
               (found by compatibility testing, all 7 browsers).
               STATUS: FIXED AND DEPLOYED (services/developer-portal.js). The
               page now uses each environment's DASHBOARD_URL setting (on
               Vercel: https://inventaapi.shop). Deployed to production on
               Nov 23, 2026 with no runtime errors; the redirect test then
               passed on all 7 browsers/devices. Visitors reach the
               dashboard through it once defect #2 (domain) is fixed.
  2  High      Custom domain inventaapi.shop points to a parked page
               (Hostinger "dns-parking"), so the site cannot be reached by
               its domain. The Vercel addresses still work.
  3  Resolved  At 20 concurrent users over a mobile hotspot, the deployed
               system missed its response-time targets (p95 2.75 s) and 2
               requests timed out. STATUS: NOT A SYSTEM DEFECT. The same
               test run from Grafana Cloud (Singapore) passed: p95 39 ms,
               0 failures (section 2.6). The hotspot was the bottleneck.
  4  Info      The tester's network allowed the database connection to open
               but held all database traffic, so the API could not be run
               against the database locally. Testing that needed the
               database was done on the deployed system instead.
